Text Formatting Tags
Tag Example
< b > This is bold text.
< strong > This is strong text.
< i > This is italic text.
< em > This is emphasized text.
< u > This is underlined text.
< mark > This is marked text.
< small > This is small text.
< big > This is big text.
< del > This is deleted text.
< sub > This is superscript text. [ H2O]
< sup > This is superscript text. [ x2]

Note : All of these tags require a closing tag.
